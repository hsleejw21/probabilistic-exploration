# Figure conventions

Save matching PDF/PNG stems without figure numbers. Synthetic plots use STIX
serif fonts, acquisition colors blue (GP-UCB), red (LogEI), green (GP-TS),
dashed Standard and solid Uniform curves. Trajectory and schedule-sweep bands
show one sample standard deviation. Keep shared legends clear of axes.
Application endpoint plots show improvements over Standard with pointwise
95% paired bootstrap intervals; filled markers indicate intervals excluding
zero. Runtime plots label methods Standard, Uniform, MVR.
Current paper acquisitions are GP-UCB, LogEI, and GP-TS. Generic tools may
support additional acquisitions, but paper entry points restrict the scope.
