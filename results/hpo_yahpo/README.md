# High-dimensional YAHPO HPO

Status: **in progress**.

The planned study covers 14D, 28D, and 38D YAHPO surrogate tasks with GP-UCB
and LogEI. It compares Standard, decay alpha 0.5, decay alpha 1, and fixed
p=0.2 using five pilot seeds followed by twenty confirmation seeds. GP signal
variance is fixed to one. Partial outputs are not interpreted as results.
