# High-dimensional YAHPO HPO

Status: **in progress**.

The planned study covers 14D, 28D, and 38D YAHPO surrogate tasks with GP-UCB,
LogEI, theory-aligned GP-TS, and MES-Gumbel. It compares Standard, decay alpha
0.5, decay alpha 1, and fixed p=0.2 on thirty confirmation seeds. All
dimensions use ten shared initial Sobol points; total budgets are 120, 200, and
250. GP signal variance is fixed to one. Partial outputs are not interpreted
as results.
