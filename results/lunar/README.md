# Lunar Lander optimization results

12-parameter controllers, 30 seeds, 400 total evaluations including 24 initial
points; each objective averages 50 fixed terrains within the run.
The manuscript compares LogEI Standard, Uniform and Greedy Packing.
Held-out terrain results are excluded. Raw histories and rollout media are
not included. See `results/figures/fig_main_applications.pdf` for the current
exported main comparison.
